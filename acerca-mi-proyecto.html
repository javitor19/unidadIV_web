Acerca de mi proyecto

Herramientas, pruebas y gestión para un proyecto seguro

Este proyecto se desarrolló para explicar de forma clara cómo se organizan las pruebas, la liberación del software, los contenedores y la documentación en un entorno web moderno.

Inicio Contexto Tipos de pruebas Gestión de pruebas
Para construir este sitio se emplearon herramientas básicas y accesibles que permiten presentar información de manera ordenada, visual y funcional. La idea fue combinar estructura, diseño y comportamiento para que la página sea fácil de comprender y mantener.

HTML5

Se usó para organizar el contenido en secciones claras, títulos, listas y enlaces de navegación.

CSS3

Se aplicó para dar estilo, colores, espaciados, tarjetas y una experiencia visual más profesional.

JavaScript

Permite agregar interactividad como el menú, el modo oscuro, el inicio de sesión y los acordeones.

Docker

Se incluyó como parte del enfoque de contenedores para mostrar cómo un proyecto puede ejecutarse de forma consistente.

Pruebas que podrían hacerse para que no se filtren datos

Para que el proyecto sea más confiable, conviene realizar pruebas que verifiquen que la información sensible no se exponga ni se manipule de forma incorrecta. Estas pruebas ayudan a proteger la privacidad y mejorar la seguridad del sitio.

Pruebas recomendadas

  1. Validar formularios para evitar entradas vacías, incorrectas o maliciosas.
  2. Probar el inicio de sesión con usuarios correctos e incorrectos para confirmar que no se revela información privada.
  3. Comprobar que los datos guardados en el navegador, como nombres o preferencias, se almacenen de forma segura y con control.
  4. Verificar que los mensajes de error no filtren información interna del sistema.
  5. Evaluar el comportamiento del sitio con diferentes navegadores y dispositivos para detectar fallos que puedan comprometer la experiencia.

Buena gestión de la página

Una página bien gestionada debe ser clara, organizada y fácil de mantener. Esto incluye separar el contenido en secciones, usar enlaces consistentes y cuidar la estructura de los elementos visuales.

Uso de contenedores

Los contenedores permiten agrupar el proyecto y sus dependencias para que funcione igual en distintos entornos.

Documentación

Una buena documentación ayuda a entender el propósito del proyecto, cómo usarlo y cómo mantenerlo.

Organización del contenido

Separar información en bloques y páginas facilita la navegación y mejora la comprensión del usuario.

Control de cambios

El uso de Git y versiones permite revisar mejoras, corregir errores y mantener el proyecto ordenado.

Contenedores y Docker en este proyecto

  • Permiten ejecutar la aplicación de forma consistente en desarrollo y producción.
  • Ayudan a evitar problemas de compatibilidad entre sistemas.
  • Facilitan la distribución del proyecto y su mantenimiento a largo plazo.
  • Mejoran la organización al separar dependencias y servicios en unidades manejables.
