Preparación y liberación de software

En esta unidad conocerás los conceptos fundamentales relacionados con la liberación de software, desde la preparación del entorno hasta las pruebas y documentación.

Unidad IV

Los contenedores permiten empaquetar una aplicación junto con sus dependencias para facilitar su ejecución y despliegue en diferentes entornos.

Portabilidad

Permite ejecutar una aplicación de manera consistente en diferentes ambientes.

Aislamiento

Cada aplicación puede funcionar de manera independiente.

La infraestructura proporciona los recursos necesarios para ejecutar, administrar y mantener una aplicación.

Servidores Redes Almacenamiento Seguridad

Las pruebas de software permiten verificar que el sistema funcione correctamente y cumpla con los requisitos establecidos.

  • Pruebas funcionales: verifican las funciones del sistema.
  • Pruebas de rendimiento: analizan el comportamiento bajo diferentes cargas.
  • Pruebas de seguridad: permiten identificar vulnerabilidades.

Las normativas establecen criterios y buenas prácticas que ayudan a garantizar la calidad y seguridad del software.

La documentación contiene la información necesaria para comprender, utilizar, mantener y actualizar un sistema de software.

Manual de usuario Manual técnico Documentación API

Unitarias

Comprueban componentes individuales del sistema.

Integración

Verifican la interacción entre diferentes componentes.

  • Funcionales: describen las funciones que debe realizar el sistema.
  • No funcionales: establecen características como seguridad, rendimiento y disponibilidad.

La gestión de pruebas permite planificar, organizar, ejecutar y documentar las actividades relacionadas con la validación del software.
